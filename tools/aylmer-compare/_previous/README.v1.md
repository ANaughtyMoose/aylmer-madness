# Aylmer Madness - Look + Audio Compare Tool

1. Start the local server if not running: ./serve.sh (or node tools/serve.mjs 8123).
2. Capture game screenshots: node tools/aylmer-compare/capture.mjs
3. Open the comparison tool in your browser: http://localhost:8123/tools/aylmer-compare/index.html
4. Review Look and Audio tabs, fill ratings and notes (autosaves to localStorage).
5. Click "Save into repo" (File System Access) or "Export feedback" (download files).
