# references/story

Photographs for the story and art pass: the cast, the Ranger, the places and the
objects listed in `docs/ART-PHOTO-BRIEF.md`.

**This folder is gitignored and must stay that way.** The repository is public and
these are photographs of real people who did not sign up to be in it. Generated
artwork derived from them is also kept out until each person has approved their
own cards.

Naming convention: `who_year_shot.jpg`, for example `sayyad_2004_threequarter.jpg`.
Wrong year is fine, but write the year you believe it is.
