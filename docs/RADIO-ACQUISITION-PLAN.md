4. Ask archives for relevant holdings and digitization quotes. For ads, request finished full mixes, campaign region and run dates. Production dates do not establish actual broadcast dates. Request samples before paying; all spending requires an approved amount.

6. Test the first complete recording through the existing local player. Preserve original quality; WAV/FLAC is useful for a new tape transfer, while MP3 works well for playback. Light level matching is preferable to aggressive restoration. Check intelligibility over engine noise, transitions and repetition.
7. After the initial research pass and roughly two weeks allowed for replies, decide whether to use complete recordings, assemble authentic clips with separately sourced music, or explicitly broaden the date range. This is a planning allowance, not a promised response time.

## Decisions and trade-offs

- Start with one station Thomas remembers, rather than whichever archive is easiest.
- Prefer exact summer dates. Other 2004 material is a labelled fallback; 2003/2005 requires an explicit approximation decision.
- Complete broadcasts preserve pacing and local atmosphere. Assembled programming provides variety/date control but needs more sourcing, editing and provenance.
- Audio remains normal speed: a one-hour recording spans 2.5 game days at the default clock rate. Start with an archival cassette mode. Later separate dated news/weather/time announcements from reusable music/idents. Never accelerate songs to match the game clock.
- Track access and public reuse separately. Ask who can authorize game distribution/editing and what third-party material is excluded. A collector's copy or archive access does not establish permission for every component. Keep research recordings outside public bundles and GitHub until reuse is established.
- Optional exploratory digitization budget: CAD $100–300, only if Thomas chooses. This is a proposed spending cap, not a vendor quote or music-licensing estimate. Begin with free research and obtain itemized quotes.
