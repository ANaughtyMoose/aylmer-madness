# V0-04 report: QA tools

Branch `vw/V0-04`, based on `fix/look-on-qr` ca9da98 (the build with the opening). Tooling only: no change under `src/`.

## What was built

| Tool | What it does |
|---|---|
| `tools/aylmer-compare/poses.json` | 8 eye poses, 6 chase poses (one on the hood cam), 9 environments, sets `core`, `chase`, `allday`, `perf8`, tagged look-diff regions |
| `capture.mjs --poses=... --env=... --look= --tag= --out= --task=` | named-pose capture on SwiftShader; ports from `CMP_SRV_PORT` / `CMP_CDP_PORT`; no `--poses` keeps the original reference mode (now with `free`, `eye`, `alt` poses and shots in `game-shots-v3`) |
| `tools/qa/look-diff.mjs` | contact sheets (before / after / 2009 ref, regions outlined), clipped %, region means vs `assets/look/palette.json`, pixel-diff masks, thumbnail sheet, `--identity`, `--scope` |
| `tools/qa/perf.mjs` | Metal only (refuses software), `.perf.lock`, 600 frames per pose, env, tier; interval, GPU timer query, CPU, tris, draws, heap, gpu bytes; `docs/qa/perf/<stamp>.json` |
| `tools/qa/boot.mjs` | both entries reach the menu and drive, 0 console errors, W moves the truck |
| `tools/qa/owned-files.mjs` | fails on a path outside the task's `files` globs |
| `tools/qa/vis-check.mjs` | a task's whole loop; `--full` adds look-diff, smoke_world, perf, owned-files |
| `build_index.mjs --task=` | pairs a task's runs for the Tom-gate compare page |

All tools use `node tools/serve.mjs`, a throwaway Chrome profile, headless, and close what they start (also on SIGINT or a crash).

## Things the build forced

- The committed build had no `devCam` / `hideHud`. `tools/qa/lib/rig.mjs` installs the equivalent from outside (instance overrides on the renderer: camera, car sunk for the draw, HUD, pedestrians and avatars hidden, traffic frozen). ca9da98 has the native hooks; the tools do not need them.
- Boot: "Nouvelle partie" now plays the opening. Every tool takes the "Balade libre" door (`#btnFree`) when present and the old EMBARQUE flow otherwise, and waits for `window.AYLMER` and drive mode.
- Repeatable frames: the new game opens on the job `alternateur` (marker, pinned sky), so the tools call `A.abandon()`; the renderer clock, `Math.random` and `G.time` are pinned per pose.
- The spawn (a driveway with a hedge 9 m ahead) stops the truck at 9 m: `boot.mjs` drives from the long straight (`chase_chemin_aylmer`).
- Time of day: the game has four phases; `golden` is the day-to-dusk blend at 0.45 of the cycle.

## Acceptance

- Identity proof (SwiftShader, core + chase at noon, golden, night; 42 shots, before vs after, same commit): `look-diff --identity` reports max channel diff 0 on all 42. Evidence: `references/places/_feedback/visual-wave/V0-04/{before,after,look-diff/before-vs-after}` (sheets, masks, `thumbs.png`).
- `node tools/smoke_world.mjs`: 5,993,845 tris, 9,958,434 verts, 1,044,656 near + 230,086 far house tris, 342 MB, 23/23 checks, the same numbers as before the change.
- `node tools/qa/perf.mjs --poses=perf8 --env=noon,night,rain --tier=med` on the M4 (Metal, timer query OK): 24 rows, 0 over budget (p95 interval 3.9 to 10 ms, p95 GPU+CPU under 6 ms, 100k to 166k tris, under 150 draws). Machine load average was 42 on 10 cores, so treat as an upper bound. `docs/qa/perf/20261006-010041.json`. An earlier run on the pre-opening build under load 60 missed the 16.7 ms interval on 5 rows: noise from other agents, the lock does not stop them.
- `boot.mjs`: both entries 0 console errors, W moved 144.6 m in 10 s.
- `owned-files.mjs --task=V0-04`: 0 outside.
- `npm test`: 79/79 suites pass (on the older base two timing-budget suites, `smoke_react` and `smoke_terrain`, failed once under load 60 and pass when the machine is calmer).
