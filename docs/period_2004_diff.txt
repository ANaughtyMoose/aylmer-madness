2004 vs today: OpenStreetMap differenced against the 2006 Census Road Network File
==================================================================================

GENERATED by tools/period_diff.py. Regenerate with:

    python3 tools/fetch_ottawa.py                 # Overpass -> data/raw/
    python3 tools/build_ottawa.py                 # -> src/game/ottawa_mapdata.js
    node -e "..." > data/raw/osm_roads.json       # dump MAP.roads (see the tool)
    python3 tools/period_diff.py > docs/period_2004_diff.txt

The game is set in the summer of 2004; OpenStreetMap is current. Statistics
Canada's 2006 Road Network File (grnf000r06a_e, all of Canada, 1.87M arcs) is
real surveyed street centreline from two years after the setting, so a street
missing from it did not exist in 2004.

Matching is geometric, never by name: each centreline is sampled every 25 m and
asked whether any 2006 arc passes within 45 m. Names are compared only on pairs
that already agree in space.

READ THE THREE SECTIONS DIFFERENTLY:

  BUILT SINCE   High confidence where a name is marked ALL — every metre of it
                is absent from 2006. Those are the ones src/game/period2004.js
                actually deletes (minus Vittoria Street, a pre-Confederation
                Ottawa lane the census file simply never carried).
                A partially-flagged name is usually a widened or realigned older
                street, not a new one, and is NOT deleted.

  REMOVED SINCE Mostly noise. The 2006 file covers all of Canada and the OSM
                extract does not, so an arc near the download boundary is
                "missing" for reasons that have nothing to do with 2004. Only
                arcs wholly inside the OSM footprint are listed, which helps,
                but the Transitway entries are the genuinely interesting ones:
                those alignments are now the Confederation Line.

  NAME DIFFERS  Treat as leads, not facts. Downtown Ottawa's one-way pairs sit
                40 m apart, so Albert/Slater and Queen/Sparks match each other
                constantly. Nothing here is applied automatically; the two
                renames the game does apply are hand-checked and listed in
                src/game/period2004.js.
