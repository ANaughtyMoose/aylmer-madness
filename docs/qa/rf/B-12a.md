## What changed

src/main.js
- **Y (B-01a).** `doTow` calls `tow.returnToOwnVehicle(G, 'tow')` in free roam. While a job is live (`G.mission && !G.mission.failed`) it stays `tow.callTow(G)`. This fixes the code-review major: a mid-job swap from a borrowed car dropped riders and ran stages built for the other car's seats. `swapCar` is unchanged, because golfnuit's own swaps go through it (B-01a contract note 3).
- **Job start (B-01b).** `startMission` calls `ensureOwnVehicle(def, G)` with G, statically imported from jobready.js. The call sits after `closeMission('quit')`, so a set piece that lent the cart gets it back first (review minor), and before `def.build`. On refuse: toast, GPS to the truck, return false. On swap: toast, then carry on. There is no other garage hand-back site in main.js, so `handBack` is reached only through `ensureOwnVehicle`.
- **Fail card (B-07).**
  - `failMission` no longer toasts. `offerRetry` sets the card; the no-offer branch calls `setFailToast`. Then `hud.failCard(failToast())`.
  - `frame()` syncs `hud.failCard(failToast())` every frame, before any early return. It calls `clearFailToast()` whenever a card is up: cinema (job brief, job done), story, or ending. That covers the review major, where the fail line froze over the ending cards.
  - `cancelRetry` in startMission still clears it.
  - The day rule uses `failSpendsDay(m)`.
  - The pause-menu Restart and Abandon now use `restartCostsDay(m) && !storyFail(m)`, so a story job never spends a day on any way out (review minor: Backspace was free, Abandon was not).
- **Feel (B-09).**
  - `G.feelFx = createFeel({ sink: G.feel })`, so `AYLMER.feel()` carries `offset` and `hitstops`.
  - frame(): `G.feelFx.update(dt); dt *= holdsSlowmo() ? 0 : slowmoScale(dt)`.
  - `AYLMER.step`: `update(dt)`, and `slowmoScale` only when not holding, which is the review's exact guard. step() still ticks during a hitstop, so the harness keeps its step count.
  - Crash rung: the event fires from `v.lastHit` only (hit(): walls, poles, traffic, parked cars, cops), and never on a landing tick. Kerbs, lips and landings no longer give a hitstop (review major). It fires before `fireSlowmo`.
  - Cop contact is detected as `v.lastHit` rising across `G.cops.update`.
  - Small rungs: `nearMiss` (from `G.traffic.nearMisses.length`), `mailbox` (propsSmashed rose), and `gravel` (`v.kind` gravel or dirt above 20 km/h; feel.js rate-limits it).
  - Camera: angles are added to camPitch, shakePitch and shakeYaw. The position offset goes on a reused copy of the eye (`FEEL_EYE`) passed to `r.begin`, never into `G.camPos` (review minor). There is no translation in the cab or while camclip guards the boom. The offset is skipped under devCam and cineCam.
  - `G.feelFx.clear()` runs on Y, T, startMission, enterDrive and toMenu.
- **Audio (B-13a contract 3).** The radio fade-in in `openingDone` is guarded with `audio.running`.
- **Load and menu (B-01a review minor).** `enterDrive` and `toMenu` call `hud.clearToasts()`, so golf night's toasts do not play in the newly loaded game.
- **Test hooks.** `AYLMER.fail(why)` (the failMission path that Backspace takes) and `AYLMER.failCard()`.

src/game/hud.js

- `Hud.failCard(ft)`: shows retry.js's card once, urgent, in the front slot, and takes it down when retry.js drops it.
- `Hud.clearToasts()`.
- `_paintToasts()` is factored out of `_pumpToastsNow`, with no behaviour change.
