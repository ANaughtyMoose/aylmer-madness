# A-03 Failing is a joke, retry is free

Branch ra/A-03 off fix/look-on-qr. Owned files only: src/game/retry.js (new), assets/text/fails.json (new), src/game/missionkit.js, src/game/calendar.js, plus tools/smoke_retry.mjs (new, the plan's self-check smoke) and this report.

## What changed

- **src/game/retry.js (new).** `classifyFail(why, mission)` sorts every fail text the game writes into one of ten reasons (tow, late, police, clock, rival, lost, caught, broke, heat, other) or 'quit'. `offerRetry({G, mission, reason, stage, why, refunded})` builds the offer on G.retry: the gag line, the stage to retry, and a `saved` object in the exact shape `resumeMission(saved)` in main.js already takes. `tickRetry(G, dt, input)` runs the 45 s window, takes R (and consumes KeyR so the radio does not also toggle), and settles the deferred day when the window runs out. `applyRetry`, `cancelRetry`, `retryCard`, `retryPrompt`, `loadFails`.
- **First retry is free.** The fail's day goes on the slate (calendar.deferDay) instead of being spent; taking R forgives it; letting the window lapse, or starting another job, settles it. The pay refundJob clawed back is returned on the free retry. A second fail of the same job still offers R but costs the day the old way, and the card says so.
- **assets/text/fails.json (new).** Two or three gag lines per reason, 24 in all, none shared between reasons. Narrator lines are Quebec French; bubbles are English and only from the main cast (Sayyad, Zahra, Margaret). No em dashes. Card strings (RATÉ, the R prompt) are HUD French.
- **src/game/calendar.js.** `deferDay`, `forgiveDay`, `settleDay`; `spendDay` also pays any owed day, so a window nobody settled cannot become a free day.
- **src/game/missionkit.js.** `failCostsDay(m)`, the rule failMission applies inline today; `restartCostsDay` now calls it (behaviour unchanged).

## Contract for A-06 (main.js owner)

```js
import { offerRetry, retryCard, tickRetry, applyRetry, cancelRetry, loadFails, RETRY_CARD_MS } from './game/retry.js';
import { failCostsDay } from './game/missionkit.js';

function failMission(why) {
  const m = G.mission;
  const back = refundJob(G, m);
  const offer = offerRetry({ G, mission: m, why, refunded: back });
  hud.toast(offer ? retryCard(offer) : 'RATÉ\n' + why, offer ? RETRY_CARD_MS : 3000);
  audio.chime(false);
  if (failCostsDay(m) && !(offer && offer.deferred)) endOfJob();
  closeMission('fail');
}
// drive loop, before the radio line reads KeyR (main.js:1999):
const rr = tickRetry(G, dt, input);
if (rr && rr.take) { resumeMission(rr.take.saved); applyRetry(G, rr.take); }
if (rr && rr.expired && calendar.isOver(G.day) && !G.summerOver) runEnding();
// startMission(def): cancelRetry(G) before anything else; same in loadIntoGame and toMenu.
// boot, next to heckle.load(): loadFails().catch(() => {});
```

Optional: `hud.prompt(retryPrompt(G))` while `G.retry` is set and no job is running, for the countdown. That is hud.js territory (A-04) if it needs a styled slot.

Covers the five plan reasons with five distinct gags; every fail text in src (source scan) and every built stage failWhy (curfew, blitz, canot included) lands on a real reason, none on 'other'; R takes the stage back on the same frame (well under 3 s); calendar day unchanged after the first retry; pay restored; second fail costs the day; expiry and a new job both settle the day; quits get no offer.

## Known gaps

- G.dayOwed and G.retry are not saved (save.js is not owned). A save made inside the 45 s window and reloaded drops the owed day. spendDay settles it at the next job only if the flag survives, which it does not across a load.
- A replay that fails and is retried does not re-mark its once-a-day replay slot (refundJob cleared it); runPay marks it again on the next paid stage.
