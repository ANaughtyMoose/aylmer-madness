# A-04 HUD declutter, a visible clock, one toast at a time

Branch ra/A-04 (worktree wt-ra-A-04), base fix/look-on-qr. Owned files only:
src/game/hud.js, src/game/ui.js, style.css, tools/qa/hud-overlap.mjs (new), this report.

## What changed

- **Clock from second one.** `Hud.setTimer(null)` now looks at the running job
  (`window.AYLMER.G.mission`, via `Hud.peekMission()`) and, when a later stage
  has a deadline, shows that budget dim and still with « plus tard »
  (`#timer.pending`). Pure helper `upcomingDeadline({mission, scale})` scales
  like main.js applyStage. Covers curfew, highwayhull, arcsurchauffe, blitz
  where the first stage is untimed.
- **One toast at a time, 2.5 s.** The Hud runs `ToastQueue(1, {minMs: 2500})`.
  A line already showing or queued is not queued again. `hold()` is now
  reason-keyed (modal, yield) so one hold does not release the other.
- **Max 2 centre text layers.** `Hud.layoutCentre()` ranks prompt > story
  bubble > toast > street chatter > tutorial tip > prompt2 and puts
  `.hud-yield` (visibility hidden) on the rest. The owner keeps its state; a
  yielded toast is frozen so it plays in full once back. Runs at most every
  100 ms from setSpeed, and at once on toast or prompt changes.
- **Handbrake tip (tut.hand).** Hidden below 5 km/h, only counts time above
  it, clears on any pull above 5 km/h, and lets go by itself after 25 s of
  driving (it used to need a pull above 12 km/h and stayed forever).
- **FRÔLÉS / CASSÉS off the minimap.** `#reactstats` sits above the map;
  hud.js publishes `--mapsize` on resize.
- **Centre text boxed.** Toast lines get the same dark rounded box as the
  prompt and the tip.

## Contract notes

- No main.js change needed: main.js already calls `hud.setTimer(null)` every
  frame on untimed stages and exposes `G` (with `mission`, `timerScale`) on
  `window.AYLMER`. If a later task renames those, override `Hud.peekMission()`.
- The overlap check (`tools/qa/hud-overlap.mjs`) has a `--unit` half that runs
  without a browser; the live half boots its own server and headless Chrome on
  CMP_SRV_PORT / CMP_CDP_PORT.

- **Clock painted when the stage is applied.** `setObjective` queues a
  microtask that paints `mission.timeLeft` (or the upcoming budget), so a
  timed job shows its clock before the first mission tick. Before this, a slow
  first frame showed highwayhull and arcsurchauffe with no clock.
